# MicroBreedR

An R package for microbiome-informed plant breeding.

## Vision

MicroBreedR aims to integrate:

- Plant genomics
- Microbiome data
- Phenotypic traits
- Environmental variables
- Multi-omics analyses

to enable microbiome-assisted breeding and crop improvement.
